# Exchange package

Flask app for the classroom blockchain exchange. Git history in this folder includes the 2019 commits from [Maktm/blockchain-exchange](https://github.com/Maktm/blockchain-exchange), imported with `git subtree`.

From the repository root:

```bash
python -m exchange
```

Setup, tests, and the browser demo are documented in the root README. The 2019 `requirements.txt` that pinned Flask 1.0 is not used.
